# Лекции

Здесь выкладываются конспекты лекций. Каждый из них содержит лекцию, но по содоержанию шире, так как всегда хочется немного больше...

Чтобы у вас не было проблем с пониманием основной терминологии и чтобы напомнить основные вещи из теории вероятности (в этот раз без них точно никуда), для вас есть Лекция 0, которая в лкассе не рассказывается, но её понимание -- пререквизит и ваша гарантия комфортного освоения.
